# Lesson 01 — Exercises

Four exercises, each adding one new concept on top of the last. Do them in order — later ones assume you're comfortable with what the earlier ones taught.

| # | Exercise | New concept added | Builds on |
|---|---|---|---|
| 1 | [Basic UI Pipeline](01-basic-ui-pipeline.md) | Multi-stage Declarative Pipeline via the UI | — |
| 2 | [Parameters & Conditional Stages](02-parameters-and-conditions.md) | Build parameters, `when` conditions | Exercise 1 |
| 3 | [Pipeline as Code, Custom Script Path](03-pipeline-as-code-custom-path.md) | Jenkinsfile in Git, non-root Script Path | Exercise 1–2 |
| 4 | [Multibranch with Branch-Specific Logic](04-multibranch-branch-logic.md) | Multibranch Pipeline, branch-conditional stages | Exercise 1–3 |

Each exercise file has: an objective, a task description (figure out the implementation yourself), hints you can expand if stuck, and a checklist to confirm you're done before moving on.
